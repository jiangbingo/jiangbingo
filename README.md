## 关于我

从嵌入式软件到 LLM 平台工程，我关注如何将模型能力转化为**可控、可观测、可评测**的真实业务系统。持续探索模型服务、知识检索、智能体工作流、自动化与面向开发者的产品体验。

## 代表性工程实践

### LLM 平台与 Agent EDA

围绕复杂工程场景，探索将模型服务、异步任务、受控执行节点与领域验证连接为可运营的工程闭环。

- 设计统一的对话与流式服务入口，隔离不同推理后端的实现差异。
- 覆盖模型注册、部署、推理与评测等生命周期环节，支持可追踪的任务编排。
- 将 AI 辅助编程接入受控的编译、仿真与验证工作流，强调可复核的结构化产物。
- 通过权限、审计、评测记录和观测反馈支撑持续迭代。
